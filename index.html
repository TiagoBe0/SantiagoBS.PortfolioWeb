Sobre mí

// proactivo, organizado y responsable

Investigo daño por radiación en materiales mediante simulaciones de dinámica molecular en CONICET, y construyo el software que las vuelve utilizables: herramientas de postprocesado con machine learning, dashboards de análisis y aplicaciones web completas.

Vengo de la física, pero paso la mayor parte del tiempo escribiendo código: C++ para motores y simulación, Python para ciencia de datos, Java / Spring para backend. También doy clases de programación web, que es donde aprendí a explicar sistemas complejos de forma simple.
